# 7 Seas Enterprise

This project is a React + Vite website for 7 Seas Enterprise, featuring Tailwind CSS for styling.

## Development

Install dependencies and run the local development server:

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

## Build

Create a production build with:

```sh
npm run build
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
